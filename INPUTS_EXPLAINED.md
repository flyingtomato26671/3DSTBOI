# Controls

Move with the Circle Pad and shoot with ABXY. No C-stick or Circle Pad Pro is needed.

## Gameplay

| Input | Action |
| --- | --- |
| Circle Pad | Move. |
| Y / A / X / B | Shoot left / right / up / down. |
| L | Place a bomb. |
| SELECT | Use the active item. Replaces ZL. |
| R | Use the held pill/card. |
| Hold D-pad Down | Drop held items. Replaces ZR. |
| START | Pause. |

D-pad Down no longer moves the character, avoiding a conflict with Drop. Circle Pad Down and menu Down still work. Movement and shooting are independent.

## Menus and saved controls

Circle Pad/D-pad navigate, A confirms, and B goes back. The touchscreen keeps its original behavior.

Saved bindings can override the new defaults. Reset or remap them in the main menu's **Options > Controls**. The pause menu does not contain the full Controls screen.

Tutorial art and the electronic manual are unchanged: ZL hints now mean SELECT, and ZR hints mean D-pad Down.
